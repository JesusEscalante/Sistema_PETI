# Sistema_PETI

## Descripción
Este proyecto es una aplicación web desarrollada con el framework Laravel. Incluye una base de datos SQL con el archivo `db_peti.sql` para la configuración inicial.

## Estructura del Proyecto

```bash
├── app/                # Lógica central de la aplicación
├── bootstrap/          # Archivos de arranque del framework
├── config/             # Configuraciones del sistema
├── public/             # Punto de entrada público (index.php, assets)
├── resources/          # Vistas, idiomas y assets compilables
├── routes/             # Definición de rutas de la aplicación
├── storage/            # Logs, caché y archivos generados
├── vendor/             # Dependencias de Composer
├── .htaccess           # Configuración para servidores Apache
├── artisan             # CLI de Laravel
├── server.php          # Servidor de desarrollo temporal
├── .gitignore          # Archivos ignorados por Git
├── README.md           # Documentación del proyecto
├── db_peti.sql         # Backup/Dump de la base de datos
